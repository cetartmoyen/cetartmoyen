# Cet Art Moyen

Site de photographies, statique (HTML/CSS/JS sans compilation), publié avec GitHub Pages.

- `index.html` : tout le site (styles, séries, visionneuse, planche-contact).
- `img/l/` : images en 1800 px (WebP), `img/s/` : vignettes en 640 px.

Pour ajouter une photo : la convertir dans les deux tailles, puis l'ajouter à la liste `SERIES` dans `index.html`.
